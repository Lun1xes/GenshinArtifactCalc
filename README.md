# ⚙️ Genshin Artifact Calculator v2

Калькулятор и анализатор артефактов для Genshin Impact с современным GUI на **CustomTkinter** в стилистике игры. Оценивает качество и потенциал артефактов по дискретным роллам 5★, визуализирует распределение роллов, поддерживает сравнение двух артефактов side-by-side, импорт из Enka.Network, Inventory Kamera и формата GOOD JSON.

## 🚀 Установка и запуск

### Требования

- **Python 3.10+**
- **Windows** (для GUI и сканера Inventory Kamera)

### Установка зависимостей

```bash
pip install customtkinter Pillow
```

### Запуск калькулятора

```bash
python calculator.py
```

### Запуск тестов

```bash
python -m unittest discover -p "test_*.py"
```

## 🎨 Особенности интерфейса и функционала

- **Стилистика Genshin Impact**: глубокая тёмная палитра (`#0f0f1e` / `#1a1a2e` / `#16213e`) с золотыми (`#ffd700`) и бирюзовыми (`#00e5ff`) акцентами.
- **Единое All-in-One окно (Single Window GUI)**: все модули объединены в одном главном окне (`1200x820`, с центрированием на экране и аппаратным композитингом DWM). Окно перемещается плавно без микрофризов и нагрузки на процессор благодаря оптимизированному рендерингу и ленивой загрузке экранов (`_history_built`, `_compare_built`, `_hub_built`).
- **Автоматическое переключение вкладок**: при выборе или переносе артефакта из сканера рюкзака (Kamera), витрины Enka.Network, файла GOOD JSON или истории окно автоматически переключается на калькулятор и мгновенно рассчитывает PAV и рекомендации.
- **Сегментные кнопки слотов с эмодзи**: быстрый выбор слота кликом по иконке:
  - 🌺 Цветок жизни
  - ✒️ Перо смерти *(универсальный глиф U+2712, корректно отображается на всех версиях Windows без пустых квадратов)*
  - ⏳ Пески времени
  - 🍷 Кубок пространства
  - 👑 Корона разума
- **Выбор сета артефакта**: встроенный каталог из 27 пятизвёздочных наборов (Золотая труппа, Охотник Сумеречного двора, Эмблема, Обсидиановый фолиант, Свиток героя сожжённого города и др.). При импорте из Enka, Kamera или GOOD сет определяется автоматически.
- **Двухуровневый селектор персонажей и стильные аватары**:
  - Первый список — быстрый алфавитный поиск героя (130+ персонажей, от Фурины и Невиллета до Арлекино, Мавуики и Часки).
  - Второй список — выбор конкретной роли (например, *«Sub-DPS / Буфер»* vs *«Main DPS (Вейп / С6)»* для Фурины).
  - Круглый динамический аватар активного героя с цветной рамкой соответствующей стихии (Гидро, Пиро, Анемо, Дендро, Электро, Крио, Гео).
  - Асинхронная подгрузка и локальное кэширование иконок в `.cache/icons/` — абсолютная отзывчивость GUI без фризов.
- **Информационная карточка билда**:
  - Рекомендуемые наборы артефактов (с иконками слотов).
  - Оптимальные основные статы для ⏳ Песков, 🍷 Кубка и 👑 Короны.
  - Топ-3 рекомендуемых оружия для выбранного билда (включая русские локализованные названия).
  - Требования к ВЭ (Energy Recharge) и ключевые нюансы ротации.
- **Прогноз улучшений до +20 (Математика AnimeGameData)**:
  - Для непрокачанных артефактов (< +20) рассчитывается комбинаторный прогноз роллов.
  - Отображение вероятностей достижения рангов **S+** (≥65% PAV), **SS+** (≥80% PAV) и **SSS** (≥90% PAV).
  - Математическое ожидание итогового PAV и Crit Value (CV) на 20 уровне.
  - Инвестиционный вердикт и стратегический совет по расходу моры и пыли (например, *«💎 Высокий потенциал (Качать обязательно)»* или *«⚠️ Высокий риск (Корм для мистического подношения)»*).
- **Оценка совместимости и рекомендации носителей**:
  - Карточка совместимости проверяет правильность основного стата, совпадение сета и полезность сабстатов под выбранного героя (с выводом вердикта: ⭐ Идеально, ✅ Отлично, ⚠️ Приемлемо, ❌ Не подходит).
  - Алгоритм поиска лучших носителей ранжирует всех персонажей игры под данный кусок.
  - Кнопка **«Примерить»** позволяет в один клик переключить билд на рекомендованного героя и мгновенно пересчитать PAV без стирания введенных статов.
- **Мини-карточки сабстатов**: структурированный ввод каждого сабстата с выпадающим меню, полем значения и цветовым индикатором веса.
- **Крупная карточка ранга и превью артефакта**: динамическое отображение ранга (SSS, SS, S, A, B, C) с иконкой слота/сета, цветовой индикацией и шкалой прогресса PAV.
- **Визуализация распределения роллов**: горизонтальные прогресс-бары для каждого сабстата, показывающие долю и количество роллов с цветовой подсветкой по важности для роли.
- **Удобный модуль сравнения артефактов (Side-by-Side)**:
  - Компактный список выбора вместо гигантских выпадающих меню на весь экран.
  - Фильтры по слотам (`🌺`, `✒️`, `⏳`, `🍷`, `👑`, `Все`) для мгновенного сопоставления однотипных артефактов.
  - Возможность в один клик сравнить текущий артефакт из калькулятора с любым артефактом из истории.
  - Наглядное сопоставление сабстатов с цветными дельтами (`▲ +diff` / `▼ -diff`) и вердикт по суммарному потенциалу.
  - Кнопки загрузки любого из сравниваемых артефактов обратно в калькулятор.
- **Поддержка раскладок Windows**: встроенная обработка физических скан-кодов для Ctrl+C, Ctrl+V, Ctrl+A, Ctrl+X даже при активной русской клавиатуре, плюс контекстное меню правой кнопки мыши.
- **Генерация карточки отчёта**: копирование красивого Markdown-отчёта с сетом, персонажем, статами, рангом и прогнозом до +20 для шеринга в Discord/Telegram.

## 🎯 Функционал импорта и экспорта

- **Enka.Network**: скачивание витрины по UID игрока с возможностью выбора персонажа, автоматическим определением сета и переноса артефакта в один клик.
- **Inventory Kamera**: запуск официального сканера артефактов с автомониторингом папки `GenshinData` и мгновенной пагинацией до 1500+ артефактов с сохранением данных о сете и надетом персонаже.
- **GOOD JSON**: импорт и экспорт отдельных артефактов и всей истории в стандартный формат Genshin Open Object Data с поддержкой полей `setKey` и `location`.
- **История артефактов**: сохранение с поиском, фильтрацией по слоту, рангу и экипировке (рюкзак / надет на персонажа). При массовом импорте надетые артефакты автоматически рассчитываются по весам персонажей-носителей.

## 📐 Технические детали

- **Decimal-арифметика**: строгие расчёты через `Decimal` без накопления погрешностей float.
- **Дискретная декомпозиция роллов**: перебор комбинаций дискретных шагов 5★ артефактов (low/mid/high).
- **Валидация 3/4-stat**: контроль допустимого количества роллов для артефактов с 3 или 4 начальными характеристиками.
- **Потокобезопасность**: сетевые запросы, скачивание иконок и фоновые процессы запускаются в отдельных потоках без блокировки GUI.
- **Покрытие тестами**: 129 автоматических модульных и интеграционных тестов.

## 📄 Источники данных

- **Paimon.moe**: мета-билды, приоритеты сетов артефактов, требования к ВЭ и рекомендации оружия.
- **Genshin-DB**: полная база русской локализации персонажей, сетов и артефактов, CDN-ссылки на ассеты.
- **AnimeGameData / Dimbreath**: точные таблицы шансов выпадения сабстатов (`SUBSTAT_SPAWN_WEIGHT`), веса главных характеристик и дискретные шаги прокачки.
- **KeqingMains (KQM) & Akasha System**: экспертные веса статов и оптимизация под актуальные версии игры (5.x+).
